# Изменения

## 1.2.1 — 2026-10-19 (Codex)
- По прямому указанию Романа задача считается выполненной только после проверки всего заявленного функционала навыка: активных маршрутов, инструментов и прежних рабочих случаев.
- Обязательна матрица функций, критериев, методов и первичных подтверждений. Непроверенное и FAIL/UNKNOWN/STALE блокируют полное завершение; частичный этап не называется полной проверкой навыка. Актуальные прежние подтверждения можно переиспользовать, разные виды проверки не подменяются друг другом.

## 1.2.0 — 2026-10-19 (Codex)
- Первый разрешённый отдельный агент выявил проблему эталона T4 и неоднозначность объекта статуса T1/T6: эталон исправлен, критерии уточнены. Исходные ответы и строгий результат 3/6 сохранены вне навыка; повторного независимого прогона изменённых заданий не было.
- Добавлены шесть переносных сценариев с отдельным эталоном и происхождением; два основаны на воспроизведённых SC-01/SC-02. Прежние 13 учебных случаев сохранены.
- scenario_suite: пакет без полей эталона, фиксация решений до сравнения, проверка привязки пакета/решений; независимость модели автоматически не утверждается.
- verify_evidence: чтение только названных файлов, SHA-256 и выбранных полей первичного JSON, отдельные BOUND/STALE/UNKNOWN/INCONSISTENT. BOUND не означает смысловой PASS или доказательство запуска.
- Исключительная публикация полного JSON через временный файл; старые результаты сохраняются. Добавлены проверки реального убийства дочернего процесса посреди записи и продолжения после него.
- GitHub Actions: прежние и новые детерминированные проверки на Python 3.9/3.12 при изменениях репозитория; без расписания и автоматического аудита пользовательских задач.
